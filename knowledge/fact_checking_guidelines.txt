FACT CHECKING GUIDELINES

A factual claim should be evaluated using
multiple independent sources.

Prefer primary sources when available.

Government sources, official organizations,
scientific institutions and original documents
should receive higher evidentiary weight.

A social media post alone should not be treated
as sufficient evidence.

The publication date must be considered.

The geographic context must be considered.

Do not conclude that a claim is false merely
because no evidence was found.

Distinguish between:
- TRUE
- MOSTLY TRUE
- UNVERIFIED
- MISLEADING
- LIKELY FALSE
